## Como Compilar
En la terminal se debe ingresar el siguiente comando

```bash
g++ -Wall -Wextra -std=c++17 tarea2.cpp -o torneo
```
Luego ingresar el archivo config.txt y su respectivos valores de N y M

```bash
./torneo 8 2 config.txt
```
Debo recalcar que los valores de N y M es a su criterio, los valores mostrado en el comando es de muestra.
